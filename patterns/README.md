# Patterns

Status: Draft  
Layer: III-IV  
Scope: Reusable conceptual, editorial, and implementation structures

## Purpose

The `patterns/` directory contains reusable structures that can be applied across books, specifications, educational material, AI-facing knowledge systems, and the living digital edition.

Patterns are not canon by default.

They may express, implement, or illustrate canon, but they remain living material unless deliberately canonized.

## Pattern Standard

Each pattern should include:

- name
- problem
- context
- structure
- canonical relationship
- examples
- status
- provenance

## Initial Pattern Areas

The first pattern areas should include:

- document identity
- provenance tracking
- relationship mapping
- canonization workflow
- chapter publication
- glossary integration
- RFC review
