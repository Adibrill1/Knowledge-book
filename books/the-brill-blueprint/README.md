Status: Draft

## Purpose

This directory contains the book edition of The Brill Blueprint.

Each chapter should remain an independent Markdown document. The book is not treated as a single manuscript file because the repository itself is designed to preserve provenance, relationships, status, and evolution at the document level.

## Editorial Rule

Each chapter should be readable as a chapter and addressable as a knowledge artifact.

That means each chapter should include:

- status
- provenance
- abstract
- relationship to canon
- key concepts
- revision notes
