# Canon

Status: Draft Canon  
Layer: I-II  
Scope: Stable constitutional and architectural documents

## Purpose

The `canon/` directory contains the stable documents that define the identity, principles, architecture, language, and governance of the Brill ecosystem.

Canon is intentionally small.

It should not contain every useful explanation, example, debate, or implementation detail. Those belong in books, commentary, RFCs, cases, patterns, diagrams, glossary entries, and the living digital edition.

## Canonical Documents

```text
Constitution.md   Enduring commitments of the ecosystem.
Principles.md     Durable rules of judgment.
Architecture.md   Structural model of the knowledge system.
Language.md       Symbolic and editorial vocabulary.
Governance.md     Change control and canonization process.
```

## Canon Rules

Canonical documents should be:

- stable
- concise
- traceable
- relationship-aware
- slow to change
- connected to living commentary

## Change Rule

Substantive changes to canon should normally begin as an RFC.

The recommended path is:

```text
draft -> commentary -> RFC -> review -> canon
```

This protects the canon from premature expansion while still allowing the system to learn.
