# Language

Status: Draft Canon  
Layer: II - Architecture  
Scope: Symbolic and editorial language

## Purpose

The Language document defines the controlled symbolic vocabulary of the Brill ecosystem.

This language supports books, diagrams, specifications, educational material, AI-readable structure, and the living digital edition.

## Symbolic Grammar

The current canonical symbols are:

```text
⬤ Entity
⇄ Relationship
◈ Context
◐ Perspective
◉ Identity
≈ Trust
↺ Transformation
◎ Meaning
⬡ Architecture
∞ Evolution
```

## Symbol Principles

Symbols should be:

- stable enough to be recognized across contexts
- simple enough to teach
- expressive enough to combine
- restrained enough to avoid decorative misuse

## Editorial Language

The project distinguishes between:

- canon: stable constitutional or architectural material
- commentary: living explanation, research, examples, and interpretation
- RFC: a proposed change or extension
- pattern: a reusable structure or method
- case: an applied example
- glossary term: a controlled definition

## Naming Principle

Names should favor durability over cleverness.

A good name should remain understandable to future readers who do not know the original conversation that produced it.

## AI-Facing Language

AI systems should be given explicit signals about:

- document status
- conceptual dependencies
- canonical authority
- uncertainty
- relationship to related documents

The system should not rely on implied context when explicit structure is available.
