# Governance

Status: Draft Canon  
Layer: I - Constitution  
Scope: Decision-making, review, and change control

## Purpose

Governance defines how the Brill ecosystem changes without losing coherence.

It protects the difference between living exploration and canonical authority.

## Governance Commitments

1. Canon changes require deliberate review.
2. Commentary may evolve quickly.
3. Provenance must be preserved for important changes.
4. Disagreement should be represented before it is resolved.
5. Repository structure should serve knowledge clarity.
6. Version history should remain meaningful.

## Status Levels

Recommended document statuses:

```text
Draft

Stable

```

## Canonization

A document or idea may become canonical only when it is:

- clearly defined
- broadly reusable
- stable across contexts
- connected to existing canon
- reviewed for downstream impact

## RFC Path

Significant changes should move through RFCs before becoming canonical.

An RFC should include:

- problem statement
- proposed change
- affected documents
- rationale
- alternatives considered
- migration notes
- decision status

## Deprecation

Deprecated material should not disappear without explanation.

When possible, it should identify:

- why it was deprecated
- what replaces it
- what historical value remains
