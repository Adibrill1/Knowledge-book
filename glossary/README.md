# Glossary

Status: Draft  
Layer: II-III  
Scope: Controlled vocabulary

## Purpose

The glossary defines important terms used across The Brill Blueprint and the broader Brill ecosystem.

Glossary entries should help readers and AI systems understand terms consistently across canon, books, diagrams, RFCs, cases, patterns, and the living digital edition.

## Entry Standard

Each glossary entry should include:

- term
- short definition
- expanded explanation
- canonical relationship
- related terms
- status
- provenance

## Initial Terms

The initial glossary should include:

- canon
- commentary
- provenance
- relationship
- context
- identity
- trust
- architecture
- evolution
- meaning
