# Roadmap

Status: Draft  
Layer: III - Implementation  
Scope: Repository development sequence  
Updated: 2026-07-04

## Purpose

This roadmap defines the near-term development sequence for Knowledge-book.

It is a working document, not canon. It should evolve as the repository becomes more capable of supporting books, specifications, educational material, AI systems, open standards, and living documentation.

## Phase I: Editorial Foundation

Status: In progress

Purpose:

Establish the repository as the canonical implementation of The Brill Blueprint.

Primary outputs:

- `README.md`
- `EDITORIAL-STANDARDS.md`
- `canon/Constitution.md`
- `canon/Principles.md`
- `canon/Architecture.md`
- `canon/Language.md`
- `canon/Governance.md`
- `books/the-brill-blueprint/Chapter-Template.md`
- `rfc/RFC-Template.md`
- `books/the-brill-blueprint/Chapter-01.md`

Completion criteria:

- repository identity is clear
- canon/commentary distinction is documented
- initial editorial standards exist
- chapter template exists
- Chapter 1 exists as a publication-quality draft

## Phase II: Knowledge Grammar

Status: Current

Purpose:

Define the reusable grammar that lets repository artifacts become structured knowledge objects.

Primary outputs:

- glossary entries for foundational terms
- patterns for document identity and provenance tracking
- relationship mapping conventions
- metadata conventions
- canonization workflow pattern

Completion criteria:

- first glossary entries exist
- first patterns exist
- document identity and provenance are repeatable practices
- future chapters can link to controlled vocabulary and patterns

## Phase III: Book Development

Status: Planned

Purpose:

Transform The Brill Blueprint from manuscript into a structured book edition.

Primary outputs:

- `Foreword.md`
- `Chapter-02.md` through `Chapter-16.md`
- `Epilogue.md`
- chapter-level metadata
- chapter relationship maps

Completion criteria:

- every chapter exists as an independent Markdown document
- chapters are linked to canon and glossary terms
- revision notes are included

## Phase IV: Editorial System

Status: Planned

Purpose:

Turn editorial practice into a durable workflow.

Primary outputs:

- publication checklist
- review checklist
- status transition rules
- versioning convention
- RFC review process
- deprecation process

Completion criteria:

- every substantive document can be reviewed consistently
- status labels are used consistently
- canon changes have a formal path

## Phase V: Visual Grammar

Status: Planned

Purpose:

Define and apply the symbolic language of the Brill ecosystem.

Primary outputs:

- symbol glossary
- diagram conventions
- examples of symbolic composition
- visual relationship maps

Completion criteria:

- canonical symbols are documented
- diagrams can be interpreted consistently
- visual language supports book and digital edition

## Phase VI: Living Digital Edition

Status: Planned

Purpose:

Begin the implementation of the living edition.

Planned capabilities:

- linked concepts
- expandable diagrams
- RFC integration
- glossary integration
- version history
- discussion
- pattern references
- case references

Completion criteria:

- site structure exists
- content model is defined
- first linked reading experience is implemented
