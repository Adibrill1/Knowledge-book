# Knowledge-book

## The Brill Blueprint

Knowledge-book is the canonical repository for The Brill Blueprint and the broader Brill Library.

This repository is the Single Source of Truth for the project.

Everything derives from it:

- Printed editions
- Digital editions
- RFCs
- Pattern Library
- Case Atlas
- Glossary
- Diagrams
- Website

## Repository Principles

- Understanding precedes optimization.
- Representation shapes reasoning.
- Architecture organizes knowledge.
- Context is part of knowledge.
- Knowledge evolves through transparent governance.
